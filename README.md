# Product Management Portfolio

Two self-directed product management projects by K. Bhanushree, a final-year B.Tech student in Computer Science and Engineering (AI and ML).

> These are independent practice projects, not work done for an employer. Project 1 draws on public user reports and two anonymous interviews. Project 2 uses a public synthetic dataset. Findings describe these analyses only.

## Projects

| # | Project | What it demonstrates | Tools | Status |
|---|---|---|---|---|
| 1 | [Failed UPI Payment Recovery](writeups/project1.md) | Problem framing, user research, metrics, prioritisation, experiment design | Notion, Google Sheets | Done |
| 2 | [E-commerce Funnel and Retention Analysis](writeups/project2.md) | SQL, funnel and cohort analysis, charts, recommendations | BigQuery, Google Sheets | Done |

## How the projects connect

Project 1 defines product metrics such as recovery rate, time to resolution, and duplicate payment rate. Project 2 demonstrates how to analyze a purchase funnel and repeat buying using SQL.
